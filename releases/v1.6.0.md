# sShooter 1.6.0

This release brings stamp-style resize and rotation controls to text annotations.

- A selected text label now has four corner handles and a circular rotation handle just outside its top-right corner. Drag a corner to change the font size, or drag the circular handle to rotate the label through ±180°.
- Wording stays easy to edit after rotation: the inline editor appears horizontal and centred on the label when you double-click it.
- The text size buttons now scale the selected label from its own size, so corner resizing and the toolbar controls work together instead of overriding each other.
- Resizing or rotating text is one undo step, and rotated text is baked into Copy and Save at full resolution.

The app is ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it. sShooter needs Screen Recording permission to capture the screen; grant it from the Permissions tab in Settings.
