# sShooter 1.4.0

This release refreshes the blur tool’s toolbar icon.

- The blur tool now uses a custom droplet glyph instead of the generic camera-filters symbol. Its behavior is unchanged: drag a rectangle to redact part of a capture, and the image underneath is blurred.

The app is ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it. sShooter needs Screen Recording permission to capture the screen; grant it from the Permissions tab in Settings.
