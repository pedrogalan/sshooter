# sShooter 1.0.0

First public release of sShooter, a lightweight native macOS menu bar screenshot and annotation utility.

- Capture a screen area with **⌘⇧2** and open it in the annotation editor.
- Draw arrows, squares, and text, and blur parts of the image to redact them.
- Copy the annotated image with **⌘C**, or save a PNG with **⌘S**.
- Reopen the last capture with its annotations, selection, and zoom intact.
- Choose a save folder and optionally save every capture automatically.
- Runs in the menu bar, with a three-tab Settings window (General, Permissions, About).
- Universal app for Apple silicon and Intel Macs, requiring macOS 14 or later.

The app is ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it. sShooter needs Screen Recording permission to capture the screen; grant it from the Permissions tab in Settings.
