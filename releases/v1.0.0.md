# sShooter 1.0.0

First release of sShooter, a lightweight native macOS menu bar screenshot and
annotation utility.

- Capture a screen area with **⌘⇧2** and open it in the annotation editor.
- Draw arrows, squares, and free text, and blur parts of the image to redact
  them.
- Copy the annotated image to the clipboard with **⌘C**, or save a PNG with
  **⌘S**.
- Reopen the last capture with its annotations intact.
- Choose a save folder and optionally save every capture automatically.
- Runs as a menu bar app and shows a three-tab Settings window (General,
  Permissions, About).
