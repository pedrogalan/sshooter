# sShooter 1.7.0

This release makes the menu capture work on the first try, keeps a chosen save folder available after a restart, and adds a launch-at-login setting.

- Choosing **Capture area** from the menu bar now starts a drag immediately on the first click. sShooter activates and focuses the capture overlay before it appears, matching the behaviour of **⌘⇧2**.
- The selected screenshot folder is remembered even if a cloud-storage folder is still mounting when sShooter starts. The path stays visible in Settings and is used again as soon as the folder is available.
- A **Launch at login** checkbox is now available in Settings → General. It uses macOS login-item state, so it stays in sync with System Settings and asks for approval when macOS requires it.

The app is ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it. sShooter needs Screen Recording permission to capture the screen; grant it from the Permissions tab in Settings.
