# sShooter 1.1.0

This release adds two freehand drawing tools and gives every drawing tool finer control over stroke thickness.

- New **Pencil** tool: drag freehand to draw a thin, solid line.
- New **Highlight** tool: drag freehand to draw a translucent marker stroke, like a real highlighter.
- The pencil and the marker share one freehand engine but keep their own colour and thickness, so you can mix fine solid lines with broad translucent ones.
- Every drawing tool now uses a continuous thickness slider instead of fixed presets, and the slider resizes the selected annotation live as you drag it.
- The annotation window is now titled **sShooter**.

The app is ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it. sShooter needs Screen Recording permission to capture the screen; grant it from the Permissions tab in Settings.
